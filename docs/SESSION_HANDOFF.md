## Грабли сессии (чтоб не наступать)

- `payload migrate:create` без drizzle-снапшота генерит ПОЛНУЮ схему (+`DROP TABLE` во всех `down()`) — инкремент писать руками и читать глазами. Снапшот `20260726_141845_m0_news_portal.json` теперь закоммичен, следующий autogen должен диффать. Отправлено в brain письмом `payload-migrate-snapshot-trap`.
- Кириллица через `curl -d '...'` из Windows-шелла едет в БД mojibake — тестовые JSON писать в файлы (UTF-8) и слать `--data-binary @file`.
- Прод-домен с этой машины по HTTPS не отвечает (локальная сеть) — проверять через `ssh GONBA curl localhost:3004`.
