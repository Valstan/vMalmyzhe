## Технические заметки

- Локальный `build` требует Postgres: Payload обращается к БД на пререндере. Полная сборка успешно проверена в `deploy-prod.yml`.
- Прямой HTTPS к прод-домену с текущей Windows-машины нестабилен; достоверная проверка выполняется серверным smoke в deploy workflow либо через SSH на прод-хост.
- Новые шрифты хранятся локально в `web/public/fonts/` вместе с OFL-лицензиями; внешний CDN не нужен.
- Фоновый файл `web/public/patterns/ivory-town-emboss.webp` оптимизирован до WebP.
- Миграции Payload не генерировать вслепую: перед применением проверять SQL и drizzle-снапшот.
