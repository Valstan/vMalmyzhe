## Грабли (чтоб не наступать)

- **Гейт `build` локально не запускается** — нет ни Postgres, ни Docker на машине; Payload лезет в БД на пререндере. `lint` + `typecheck` гоняются нормально. PR-гейта в CI нет (только `deploy-prod.yml` на merge в main) — значит build проверяется уже на деплое.
