# Три проверки 05.09 — по строке

## 1. Cookie — `vm_resident`, без `__Host-`, PENDING с 2026-09-12

`curl -sI https://вмалмыже.рф/` cookie не ставит (анонимный запрос, страницы
статичные); сессионная cookie ЕСА ставится в `/api/auth/callback`:
`vm_resident`, `httpOnly`, `sameSite=lax`, `path=/`, `secure` — из схемы
`redirectUri` (`https://` → true), не из «в проде». Имя без префикса → **в
классе #285**. Смягчение по факту: у нас нет действия «привязать внешний
аккаунт» — сессия без записи в БД (D-072), подброшенная cookie даёт чужую
личность на экране до выхода, необратимого шага нет. Транзакционная cookie
PKCE (`TX_COOKIE`) — тот же класс, подмена ловится подписью и nonce.
Переименование в `__Host-vm_resident` (читать оба, писать новое, гасить оба
явной перезаписью) — отдельный PR, вместе с проверкой G339 для админки
Payload (`payload-token` без префикса, `cookiePrefix`/`auth.cookies` у нас не
заданы — дефолт).

## 2. stderr `ssh` — НЕ погашен, PENDING; поправка к вашей строке о приватности

Во всех четырёх workflow с `ssh` (`deploy-prod`, `probe-prod`,
`apply-migration`, `apply-vault-config`) вызовы идут как
`ssh vmalmyzhe 'bash -s' <<'REMOTE'` без `2>/dev/null` и без ветки `rc=255`;
один шаг (журнал в `deploy-prod`) намеренно сливает `2>&1`. При обрыве связи
`ssh: connect to host <HostName из ~/.ssh/config> port <порт>` уедет в лог.
**Репо публичный с 17.08 (D-038), не приватный, как в письме 05.09** — логи
Actions читаемы всеми, так что гигиена не «та же», а обязательная. Рецепт из
письма (`set +e` … `rc=255` … stdout у удалённого скрипта) — тем же PR, что
и cookie, либо следующим. Удалённые скрипты у нас уже печатают диагностику в
stdout (`::error::` строки внутри heredoc).

`shell: bash` нет ни в одном workflow; `set -eo pipefail` ставится руками в
15 из 25 `run:`-шагов. Конвейер после `ssh` на раннере — один, в
диагностическом шаге с `|| true` по замыслу. `bash -s "$A"` с пустым
аргументом (G321) — известно и прокомментировано в `deploy-prod`, гард
`[ -n ]` стоит только там; `apply-migration` (два аргумента),
`apply-vault-config` (три), `probe-prod` (`$ESA`) без гарда — добавить в тот
же PR.

## 3. `draft: true` — одно место, ingest, по замыслу
