# Нашлось / предохранитель переписан — да

**Строка ответа:** нашлось — 6 категорий в 11 живых файлах; **предохранитель
переписан — да** (`AGENTS.md`, раздел «Публичный репозиторий — тоже

PR #46.

## Что нашлось (категории, не значения)

Обход по содержимому: пять линз (IP/хосты · бокс/хостер/жильцы · порты/пути ·
SSH/учётки · секретоподобные строки) + верификация каждой находки чтением
контекста. Как и у Портфолио — предохранитель «секреты вне репо» был написан
и соблюдался; **реквизиты** под него не подпадали.

| Категория | Где (живые файлы) |
|---|---|
| Хостнейм бокса + имя хостера + «Бокс 1» | канон `AGENTS.md` (две строки) |
| SSH-логин деплоя литералом | оба workflow (`deploy-prod`, `apply-migration`) и `deploy/*.service` |
| Абсолютные серверные пути (корень релизов с именем пользователя, путь prod-env с правами) | те же два workflow, юнит, `.env.example` (4 места), комментарии в двух файлах `web/src`, `scripts/vk-import.mjs` |
| SSH-алиас владельца + «Бокс 1» + путь prod-env в готовых командах | `docs/PUBLISHING.md`, памятка `close_session`, техзаметка handoff |
| **Хост чужого прод-бокса** (шлюз Сетки) литералом + «на боксе Сетки … issue_gateway_key.py» | `scripts/vk-fetch.mjs`, `.env.example` |
| `hostname` бокса печатался в **публичный лог CI** при каждом ручном прогоне миграций | `apply-migration.yml` |

Последняя строка — то, чего в твоём списке не было: у публичного репо публичны
и логи Actions, а `echo "host: $(hostname)"` стоял ровно там.

Не тронуто сознательно: `127.0.0.1:3004` / `localhost:3004` (dev-дефолты),
публичный домен и punycode, номер Метрики, датированные блоки handoff и
отправленные письма (история).

## Что сделано

- Логин → `vars.DEPLOY_SSH_USER`, корень релизов → `$HOME` пользователя деплоя,
  путь prod-env → `vars.PROD_ENV_FILE` — без дефолтов-литералов, пустое
  значение валит preflight. ⚠️ Грабля по пути: `gh variable set … --body
  /etc/…` из Git Bash молча записал `C:/Program Files/Git/etc/…` — MSYS
  подменяет POSIX-пути в аргументах. Поймано `gh variable get` до мержа,
  перезаписано с `MSYS_NO_PATHCONV=1`. Проверять **значения** переменных, а не
  факт их наличия.
- Юнит — шаблон с плейсхолдерами; установленная копия на боксе — источник
  истины.
- Адрес шлюза Сетки — из `SARAFAN_GATEWAY_URL` (env / `web/.env`), без дефолта.
- Реквизиты бокса — в `docs/INFRA.local.md` (в `.gitignore`, только у владельца).
