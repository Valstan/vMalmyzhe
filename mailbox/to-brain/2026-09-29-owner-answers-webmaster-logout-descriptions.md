# Ответы владельца от 29.09 — что сделано

Владелец ответил на пять открытых вопросов. Три закрыты делом в этом PR,
два — его руками с разбором ниже.

## Вебмастер: sitemap взят (п.4 чек-листа D-088)

Кабинет 29.09: `https://вмалмыже.рф/sitemap.xml` — статус ок, загрузка 21.09,
ссылок в файле 466. Вопрос «через неделю скажите» закрыт: робот файл взял.

Попутно кабинет дал три новых указания — разбираем:

1. **Поддомены в выдаче** — найдены поддомены сайта, совет добавить их в
   Вебмастер и закрыть лишнее от индексирования. Поддомены — хозяйство соседей
   по кластеру и владельца (добавление в кабинет — его руки). Передаём как факт
   к сведению, себе не берём.
2. **Яндекс Бизнес** — совет добавить организацию. Руки владельца, ему сказано
   ещё 12.09. Факт к сведению.
3. **Метатеги Description** — «на многих страницах отсутствуют или заполнены
   некорректно». Это наше, и причина найдена: страницы без собственного
   description наследовали общий `SITE_DESC` из layout — сотни дублей.
   **Починено этим PR**: уникальные description у `/news`, пагинации ленты,
   рубрик (фолбэк с именем рубрики) и пагинации рубрик, у статических страниц —
   из первого абзаца контента (общий `extractText` вынесен в `lib/lexicalText.ts`
   с тестами). У постов свой description был (SEO #051).

## Живой выход: работает, консоль шумная не по нашей вине

Владелец 29.09: вход → «Выйти из всех сервисов» → повторный вход — работает
нормально. В консоли при этом: две строки `Permissions-Policy`
(`run-ad-auction`, `join-ad-interest-group`) и пачка `ERR_BLOCKED_BY_CLIENT`
по `informer.yandex.ru` / `mc.yandex.ru/metrika/tag.js`.

Разбор: `Permissions-Policy` мы не отдаём вовсе (наши заголовки — HSTS,
nosniff, Referrer-Policy, X-Frame-Options, CSP) — эти две строки не наши.
`ERR_BLOCKED_BY_CLIENT` — блокировщик рекламы владельца режет Метрику; оттуда
же ретраи и простыня стектрейсов из чанков. Ошибок приложения в логе нет.
Просьба к владельцу — разовый повтор с выключенным блокировщиком для строки
«консоль чистая»; отдельным пунктом не заводим.
